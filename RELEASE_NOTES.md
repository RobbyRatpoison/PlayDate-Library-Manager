# Release Notes

## v1.12.0
### New

- Customizable mouse actions: choose what each mouse button does on a game cover, on a single or double click. (suggested by woutercools)
- Gamepad shortcuts for a game's store page, install folder, Steam achievements and Community Hub.
- Gamepad Setup can now choose a controller's button and stick layout, remembered per controller.
- Set up a custom controller layout step by step, with each control highlighted on a drawing. Retro pads like NES, SNES and Genesis are supported too.
- Choose how a controller's buttons are named: Xbox, PlayStation, Nintendo or Other.
- Rename any controller button yourself, such as C or Z.

### Improvements

- Gamepad Diagnostics is now Gamepad Setup, with the live view behind a button so the gamepad can use the rest of it.
- Gamepad Controls and Gamepad Setup are greyed out while gamepad input is off.
- Gamepad input is no longer labelled experimental.
- Mouse actions replace "Require double-click to launch/install". Your setting carries over.
- Picking a gamepad button already in use now asks to swap or clear the other action.
- Gamepad Controls can clear most actions, not just shortcuts.
- Gamepad Setup now shows a live drawing of the controller, plus its button count and held buttons.
- Controllers without a standard layout are now recognised from a built-in list of known layouts.
- The Library settings window is wider.

### Fixes

- Fixed "Reset to Defaults" in Gamepad Controls not updating the list until reopened.
- Fixed some controllers having the wrong buttons and right stick.
