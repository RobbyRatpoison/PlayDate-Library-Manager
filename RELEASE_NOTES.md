# Release Notes

## v2026.10.5
### New

- Added a Show File button for artwork, to open the image in your file manager.
- Added a Browse button for Custom URL, to pick a local image instead of typing its path.

### Improvements

- The From Steam button now always shows and finds the game on Steam itself.
- Syncing one game now also fetches its purchase date, for most stores.

### Fixes

- Fixed LB/RB sometimes switching two pages at once.
- Fixed gamepad focus staying behind after scrolling with the right stick.
- Fixed GOG's Import Purchase Dates button opening the userscript page instead of importing.
- Fixed the bulk date import still sending GOG and EA games to the userscript.
