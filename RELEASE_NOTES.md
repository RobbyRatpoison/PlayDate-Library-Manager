# Release Notes

## v1.11.2
### Fixes

- Fixed game names sorting capitalised titles ahead of all lowercase ones instead of alphabetically. (reported by Mayanaise)
- Fixed an external Xbox controller (such as the Elite 2 connected over Bluetooth) misbehaving in Steam Deck game mode: triggers read as permanently pressed, the left stick sat at a corner, and the right stick moved the triggers. PlayDate now reads each controller's own axis layout and ranges.
