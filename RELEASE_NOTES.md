# Release Notes

## v2026.10.8
### New
- Tuning now lists your liked and disliked tags.
- You can pin or ignore tags in your taste profile.
- Plugins can sync your library when PlayDate starts. Disabled by default, opt in per plugin. (suggested by woutercools)

### Improvements
- The game's title now shows in Edit Game Details. (suggested by woutercools)
- The card tooltip can show HowLongToBeat times. (suggested by woutercools)

### Fixes
- Fixed the Pick 6 filter not properly loading your library toggles.
- Fixed CLEAR leaving a search applied after using Filters. (reported by woutercools)
- Fixed a search being overwritten while you type it.
