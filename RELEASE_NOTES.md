# Release Notes

## v2026.10.2
### Improvements

- Backups now include cover art by default, so artwork you picked or fixed by hand isn't lost.
- Backing up is much faster, and restoring is faster too.
- "Fill Missing Data" now finds more games whose titles differ slightly from the wiki's.
- Covers that don't fit their card now get a smooth colored backdrop instead of a blur, so nothing pops in when scrolling stops.

### Fixes

- Fixed restoring a large backup using a lot of memory.
- Fixed games you own on more than one store disappearing when a filter, such as a single store, matches only one of the copies.
